# Таблица тест-кейсов

Автоматически эти сценарии проверяют Feature-тесты (`php artisan test`). Столбец «Фактический результат» заполняется после ручного прогона коллекции «Electronics Shop: заказы и бизнес-правила» в Postman (код ответа и краткий итог).

| № | Описание | Запрос | Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|---|---|---|
| 1 | Регистрация нового пользователя | `POST /auth/register` | name, email, password, password_confirmation | 201, user и token, пароля в ответе нет | 201 |
| 2 | Регистрация с занятым email и несовпадающим паролем | `POST /auth/register` | email существующего пользователя, пароли не совпадают | 422, errors по email и password | 422 |
| 3 | Вход с верными данными | `POST /auth/login` | customer@shop.kz / password | 200, token | 200 |
| 4 | Вход с неверным паролем | `POST /auth/login` | customer@shop.kz / x | 401, «Неверный email или пароль» | 401 |
| 5 | Доступ без токена | `GET /auth/me` | без заголовка Authorization | 401, JSON «Требуется авторизация» | 401 |
| 6 | Доступ с неверным токеном | `GET /auth/me` | Bearer abc123 | 401 | 401 |
| 7 | Список товаров (структура) | `GET /products` | — | 200, data, links, meta | 200 |
| 8 | Фильтр по категории | `GET /products?category_id=1` | category_id=1 | 200, только товары категории 1 | 200 |
| 9 | Фильтр по цене | `GET /products?price_min=1000&price_max=100000` | диапазон цены | 200, цены в диапазоне | 200 |
| 10 | Поиск по названию | `GET /products?search=a` | search=a | 200, названия содержат «a» | 200 |
| 11 | Сортировка по цене (убывание) | `GET /products?sort=price&order=desc` | sort=price, order=desc | 200, от дорогих к дешёвым | 200 |
| 12 | Пагинация | `GET /products?per_page=3&page=2` | per_page=3, page=2 | 200, 3 записи, meta.current_page = 2 | 200 |
| 13 | Недопустимое поле сортировки | `GET /products?sort=password` | sort=password | 422, «Сортировка возможна по полям…» | 422 |
| 14 | Несуществующий товар | `GET /products/9999` | id=9999 | 404, «Товар не найден» | 404 |
| 15 | Создание товара администратором | `POST /products` | корректный JSON товара | 201, товар в базе | 201 |
| 16 | Создание товара с пустым телом | `POST /products` | {} | 422, message и errors | 422 |
| 17 | Создание товара покупателем | `POST /products` | токен customer | 403, «Доступ запрещён» | 403 |
| 18 | Удаление товара менеджером | `DELETE /products/{id}` | токен manager | 403 | 403 |
| 19 | Удаление товара, входящего в заказы | `DELETE /products/1` | токен admin | 409, «Нельзя удалить запись…» | 409 |
| 20 | Бизнес-правило: заказ при пустой корзине | `POST /orders` | address, phone, корзина пуста | 409, «Корзина пуста: нельзя оформить заказ» | 409 |
| 21 | Бизнес-правило: больше, чем на складе | `POST /cart/items` | product_id=1, quantity=999 | 409, «Нельзя добавить 999 шт.…» | 409 |
| 22 | Оформление заказа из корзины | `POST /orders` | address, phone, корзина с товаром | 201, status = new, остаток уменьшен, корзина пуста | 201 |
| 23 | Откат транзакции при нехватке остатка | `POST /orders` | в корзине 2 товара, у второго остаток меньше | 409, остаток первого не изменился, заказ не создан | 409 |
| 24 | Заказ без адреса и телефона | `POST /orders` | {} | 422, errors по address и phone | 422 |
| 25 | Просмотр чужого заказа | `GET /orders/{id}` | токен customer, заказ другого пользователя | 403 | 403 |
| 26 | Недопустимый переход статуса | `PATCH /orders/{id}/status` | new -> delivered, токен manager | 409, «Нельзя изменить статус заказа…» | 409 |
| 27 | Допустимый переход статуса | `PATCH /orders/{id}/status` | new -> paid, токен manager | 200, status = paid | 200 |
| 28 | Отмена доставленного заказа | `POST /orders/{id}/cancel` | заказ delivered | 409, «Нельзя отменить заказ в статусе…» | 409 |
| 29 | Отмена нового заказа | `POST /orders/{id}/cancel` | заказ new | 200, status = cancelled, остаток возвращён | 200 |
| 30 | Статистика администратором | `GET /stats/overview` | токен admin | 200, orders_by_status, revenue, popular_products | 200 |
| 31 | Статистика покупателем | `GET /stats/overview` | токен customer | 403 | 403 |
