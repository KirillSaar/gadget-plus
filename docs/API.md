# Документация API: интернет-магазин электроники

Базовый адрес: `http://127.0.0.1:8000/api/v1`. Все запросы отправляются с заголовком `Accept: application/json`.

## Общие правила

- **Авторизация:** заголовок `Authorization: Bearer <token>`. Токен выдают `POST /auth/login` и `POST /auth/register`.
- **Роли:** `customer` (покупатель), `manager`, `admin`.
- **Формат ошибок** одинаков везде: `{"message": "..."}`; для ошибок валидации (422) добавляется поле `errors`:

```json
{
  "message": "Ошибка валидации",
  "errors": {
    "price": [
      "Цена должна быть больше нуля"
    ]
  }
}
```

- **Пагинация** списков: ответ содержит `data`, `links` и `meta` (`current_page`, `last_page`, `per_page`, `total`).
- Набор полей в объектах (товар, заказ) показан в виде примера и определяется классами Resource.

## Содержание

### Авторизация

- **POST** `/api/v1/auth/register`: Регистрация (роль: Гость)
- **POST** `/api/v1/auth/login`: Вход (роль: Гость)
- **POST** `/api/v1/auth/logout`: Выход (роль: Авторизованный)
- **GET** `/api/v1/auth/me`: Текущий пользователь (роль: Авторизованный)

### Товары

- **GET** `/api/v1/products`: Список товаров (роль: Все (токен не нужен))
- **GET** `/api/v1/products/1`: Один товар (роль: Все (токен не нужен))
- **POST** `/api/v1/products`: Создать товар (роль: admin, manager)
- **PUT** `/api/v1/products/1`: Изменить товар (роль: admin, manager)
- **DELETE** `/api/v1/products/1`: Удалить товар (роль: admin)

### Категории

- **GET** `/api/v1/categories`: Список категорий (роль: Все (токен не нужен))
- **GET** `/api/v1/categories/1`: Одна категория (роль: Все (токен не нужен))
- **POST** `/api/v1/categories`: Создать категорию (роль: admin)
- **PUT** `/api/v1/categories/1`: Изменить категорию (роль: admin)
- **DELETE** `/api/v1/categories/1`: Удалить категорию (роль: admin)

### Корзина

- **GET** `/api/v1/cart`: Моя корзина (роль: Авторизованный)
- **POST** `/api/v1/cart/items`: Добавить товар в корзину (роль: Авторизованный)
- **DELETE** `/api/v1/cart/items/1`: Убрать товар из корзины (роль: Авторизованный)
- **DELETE** `/api/v1/cart`: Очистить корзину (роль: Авторизованный)

### Заказы

- **GET** `/api/v1/orders`: Список заказов (роль: Авторизованный)
- **POST** `/api/v1/orders`: Оформить заказ из корзины (роль: Авторизованный)
- **GET** `/api/v1/orders/{{order_id}}`: Заказ по id (роль: Владелец, admin, manager)
- **POST** `/api/v1/orders/{{order_id}}/cancel`: Отменить заказ (роль: Владелец, admin)
- **PATCH** `/api/v1/orders/{{order_id}}/status`: Сменить статус заказа (роль: admin, manager)

### Статистика

- **GET** `/api/v1/stats/overview`: Сводная статистика (роль: admin, manager)

## Авторизация

### Регистрация

`POST /api/v1/auth/register`

**Роль:** Гость

Создаёт пользователя с ролью customer и выдаёт токен. Роль из запроса игнорируется.

**Пример тела запроса:**

```json
{
  "name": "Иван Петров",
  "email": "ivan@example.com",
  "password": "secret123",
  "password_confirmation": "secret123"
}
```

**Успешный ответ: 201 Created**

```json
{
  "user": {
    "id": 5,
    "name": "Иван Петров",
    "email": "customer@shop.kz",
    "role": "customer"
  },
  "token": "1|AbCdEf123..."
}
```

**Возможные ошибки:**

| Код | Причина |
|---|---|
| 422 | Ошибка валидации: {"message": "Ошибка валидации", "errors": {...}} |

### Вход

`POST /api/v1/auth/login`

**Роль:** Гость

Проверяет email и пароль, выдаёт токен Sanctum (живёт 24 часа). Для TTL см. config/sanctum.php.

**Пример тела запроса:**

```json
{
  "email": "customer@shop.kz",
  "password": "password"
}
```

**Успешный ответ: 200 OK**

```json
{
  "user": {
    "id": 5,
    "name": "Иван Петров",
    "email": "customer@shop.kz",
    "role": "customer"
  },
  "token": "2|XyZ987..."
}
```

**Возможные ошибки:**

| Код | Причина |
|---|---|
| 401 | Неверный email или пароль (без уточнения, что именно неверно) |
| 422 | Ошибка валидации: {"message": "Ошибка валидации", "errors": {...}} |

### Выход

`POST /api/v1/auth/logout`

**Роль:** Авторизованный

Удаляет текущий токен доступа.

**Успешный ответ: 204 No Content**

| Код | Причина |
|---|---|
| 401 | Не передан или недействителен токен: {"message": "Требуется авторизация"} |

## Товары

### Список товаров

`GET /api/v1/products`

**Роль:** Все (токен не нужен)

Список товаров с фильтрацией, поиском, сортировкой и пагинацией.

**Параметры запроса (query):**

| Параметр | Описание |
|---|---|
| `category_id` | Фильтр по категории |
| `brand_id` | Фильтр по бренду |
| `price_min` | Минимальная цена |
| `price_max` | Максимальная цена |
| `search` | Поиск по части названия |
| `sort` | Поле сортировки: id, name, price, created_at |
| `order` | Направление: asc или desc |
| `page` | Номер страницы |
| `per_page` | Размер страницы (1-50, по умолчанию 10) |

**Успешный ответ: 200 OK**

```json
{
  "data": [
    {
      "id": 1,
      "name": "Смартфон Galaxy S24",
      "slug": "smartphone-galaxy-s24",
      "description": "Флагманский смартфон",
      "price": "89990.00",
      "stock": 25,
      "is_active": true,
      "category": {
        "id": 1,
        "name": "Смартфоны"
      },
      "brand": {
        "id": 2,
        "name": "Samsung"
      }
    }
  ],
  "links": {
    "first": "http://127.0.0.1:8000/api/v1/...?page=1",
    "last": "http://127.0.0.1:8000/api/v1/...?page=3",
    "prev": null,
    "next": "http://127.0.0.1:8000/api/v1/...?page=2"

  "meta": {
    "current_page": 1,
    "last_page": 3,
    "per_page": 10,
    "total": 25

}
```

**Возможные ошибки:**

| Код | Причина |

| 422 | Неверные параметры (sort, order, per_page, price_max и др.) |
