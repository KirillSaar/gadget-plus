# Клиент Electronics Shop

Простое клиентское приложение (HTML, CSS, JavaScript, fetch) для API на Laravel.

## Запуск

1. Запустите API: `php artisan serve` (адрес `http://127.0.0.1:8000`).
2. Из корня репозитория запустите клиент на порту 5500:

   ```
   php -S 127.0.0.1:5500 -t client
   ```

3. Откройте `http://127.0.0.1:5500/login.html`.

Можно использовать и расширение Live Server для VS Code (порт 5500 по умолчанию).
Открывать файлы двойным щелчком (`file://`) нельзя: браузер не загрузит модули JavaScript.

## Настройка

- Адрес API и пути запросов: `js/config.js`.
- Адрес клиента для CORS: переменная `CORS_ALLOWED_ORIGINS` в `.env` Laravel.

## Структура

- `js/api.js` — общая функция `apiRequest` (заголовки, токен, обработка 401, 422, 5xx и ошибок сети).
- `js/auth.js` — вход, регистрация, текущий пользователь, выход.
- `js/ui.js` — вывод ошибок форм и форматирование цены.
- `login.html`, `register.html`, `products.html` — страницы.
